# UMUTONIWASE Florence Portfolio

An animated, responsive personal portfolio presenting Florence's background in software development, networking, technical support, and robotics training.

## Features

- Six interactive portfolio cards arranged around a profile portrait
- Detailed About, Skills, Experience, Projects, Education, and Contact dialogs
- Keyboard-accessible controls, focus management, and responsive modal layouts
- React Icons Kit IcoMoon icons and CSS entrance animations
- Responsive Bootstrap grid for desktop and mobile screens

## Run Locally

Install the dependencies and build the React bundle:

```bash
npm install
npm run build
```

Open `index.html` in a browser. During development, use `npm run watch` to rebuild automatically after changes to `src/app.jsx`.

## Project Structure

- `src/app.jsx` contains the portfolio data, React components, and modal behavior.
- `styles/main.css` contains Bootstrap and the custom layout and animation styles.
- `images/profile.jpeg` is the profile portrait displayed in the center circle.
- `dist/app.js` is the generated browser bundle.
